PANTHEON

Reference docs for the Pantheon media platform — Kairos (scheduling/library engine), Hades (management UI), Hermes (streaming server), Hephaestus (transcoding).

  • First-Time Setup
    From a fresh install to a playing channel: add a source, scraper API keys, sync, and build your first channel — mirrors the in-app guided tour new admins see.
  • HADES Scheduling Diagram
    How a channel fills itself — blocks, cursors, advancement modes, rerun pools, filler, and bumpers, kept in sync with the current Kairos scheduler implementation.
  • API Reference
    The full Kairos admin/management REST API — sources, libraries, channels, scheduling, scrapers, discovery, chapters, Roku pairing, and more. Everything you need to script Pantheon or build your own client.
  • Privacy Policy
    Covers the Roku channel and every other Pantheon client — what's stored where, and why there's no central Pantheon service to worry about in the first place.
